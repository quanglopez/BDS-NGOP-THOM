# BĐS Ngộp Thơm - Vercel Ready

## Deploy
1. Vào vercel.com/new -> drag folder này
2. Settings -> Environment Variables -> Add:
   JEV_API_KEY = apikey_... (lấy từ api.typesafe.ai)
3. Deployments -> Redeploy

## Local dev
cp .env.example .env.local
# dán key vào .env.local
npm i -g vercel
vercel dev
